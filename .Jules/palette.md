## 2024-05-24 - Single-click copy actions for raw output
**Learning:** Text-heavy tools outputting raw data require a single-click copy mechanism, as users frequently want to transfer the result immediately. Standard text selection is cumbersome for long outputs. Adding `aria-label` to raw output areas ensures screen readers provide context for otherwise unlabelled content.
**Action:** Always provide a dedicated "Copy to Clipboard" button with temporary visual feedback ("COPIED!") for components displaying generated text or code.
